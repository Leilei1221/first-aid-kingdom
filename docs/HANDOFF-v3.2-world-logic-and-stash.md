## 2. 目前程式的問題（已檢查 handoff3 版 `script.js`）

乾糧與開水目前**全部存在急救背包 `S.kit` 裡**，與急救用品共用格數，也沒有「家中防災包」。相關位置：

| 位置（handoff3 約略行號） | 現況 |
|---|---|
| 乾糧製造機（約 583 至 587） | 做好的乾糧直接 `S.kit.push('ration@到期日')` |
| 爐火煮水（約 707 至 712） | 開水直接放進 `S.kit` |
| 隔天結算訊息（約 613） | 只檢查背包內過期乾糧 |
| 爺爺過期提醒（約 1155 至 1157） | 只檢查背包內過期乾糧 |
| 商店賣乾糧（約 1096、1110） | 從 `S.kit` 賣出 |
| 進城前確認（約 988 至 991）、守衛對話（約 981） | 以 `S.kit` 內乾糧與開水判定 |
| 地震章末 `rationPhase`（約 1015 至 1027） | 從 `S.kit` 扣 `RATION_NEED` 包乾糧、`WATER_NEED` 瓶開水 |
| 常數（約 92） | `RATION_NEED=3`、`WATER_NEED=3` |
| 三天份文字 | 知識卡 `water`（約 134）、守衛對話（約 981）、第 10 階段目標（約 417）、開放東邊區域提示（約 1176） |

另外注意：`ALT={saline:['water']}`（約 1135）表示**開水可代替生理食鹽水沖洗傷口**，傷口事件的 `takeKit` 會從 `S.kit` 找開水。所以「要沖傷口的開水」仍需要能在急救背包裡。

## 3. 第一階段（序章）要做的事：最小改動

**目標**：在不破壞序章流程的前提下，讓「防災包放爺爺家」成立。

### 3.1 新增防災包儲存

| 項目 | 規格 |
|---|---|
| 狀態 | `S.stash = []`，物品格式與 `S.kit` 相同（例如 `'ration@23'`、`'water'`） |
| 容量 | 新常數 `STASH_CAP`，預設 **20**（可放一週份乾糧加開水還有餘裕），寫入 `content/balance.json` |
| 位置 | 序章：爺爺家，**門口附近**（出口在畫面下方）。座標請依 `walks.json` 與場景圖決定，**不可擋住出口**，並用實際走路測試走得到 |
| 互動 | 靠近時動作鍵顯示「防災包」。選單：**放入**（從急救背包放進防災包）、**取出**（從防災包取到急救背包，需有空格）、**查看**（顯示乾糧幾包與最快到期日、開水幾瓶、總數／容量） |
| 圖像 | 使用物品徽章（`badge`）暫代；之後會提供 `escape_bag.webp` |
| 重量 | 防災包內的東西**不計入**負重；取出到急救背包後才計入 |

### 3.2 生產與取用路徑（維持簡單）

| 動作 | 做法 |
|---|---|
| 乾糧製造機、爐火煮水 | **產出仍先進急救背包**（不改這兩段程式的流向），玩家要回家自己放入防災包。這樣農田離家較遠的情境也合理 |
| 急救背包格數吃緊 | 這是刻意的壓力，會促使玩家把乾糧與開水放回家 |
| 傷口沖洗用水 | 玩家自己決定留幾瓶開水在急救背包 |
| 商店賣乾糧 | 維持只賣急救背包裡的 |

### 3.3 進城與地震章末

落石之城的地震發生在城堡，**玩家人在城裡**，所以「限時挑選」不適用這裡。依原則 5 處理：

| 項目 | 規格 |
|---|---|
| 進城前提示 | 守衛的話與進城確認，改成「要自己從家裡的防災包帶出救援物資」；確認畫面同時顯示**急救背包**與**家中防災包**的乾糧、開水數量，並提示「家中防災包不能在這裡拿，要回家取」 |
| `rationPhase` 判定 | **邏輯不變**，仍從急救背包扣除（門檻 3 包乾糧、3 瓶開水，維持現行以免動到平衡） |
| 結果文字 | 若玩家把物資留在家裡：提示「你把防災包留在家裡了。平時要放在門口方便帶，也要記得出門前帶上」 |

### 3.4 過期與提醒

| 項目 | 規格 |
|---|---|
| 隔天結算 | 同時計算急救背包與防災包內過期的乾糧，訊息分開寫 |
| 爺爺提醒 | 防災包內有過期乾糧時，爺爺提醒並提供「丟掉過期乾糧」，邏輯同現有背包版 |
| 家中儲備進度 | 在「查看」畫面顯示**家中儲備目標**：乾糧 x/7、開水 y/7（一週）。**只是進度顯示，不阻擋任何劇情** |

### 3.5 文字更新（**需老師逐字審核後才寫入**）

老師已決定天數改為「居家一週、避難包輕量」。下列為建議文字，請先給老師確認：

| 位置 | 現況 | 建議新文字（待審） |
|---|---|---|
| 知識卡 `water` 最後一句 | 「防災包裡也要準備至少三天份的飲用水。」 | 「居家儲備的飲用水與食物，建議至少準備一週份；緊急避難包則挑選輕量的必需品，並定期檢查更新。」 |
| 守衛對話 | 「…也帶上 3 包乾糧和 3 瓶乾淨的水。」 | 「如果你要進城，最好先把急救背包準備好，再從家裡的防災包拿出 3 包乾糧和 3 瓶乾淨的水帶上。萬一被困住，救援可能要好幾天才能進來。」 |
| 第 10 階段目標與開放東邊區域提示 | 「準備好急救背包、3 包乾糧和 3 瓶開水」 | 「準備好急救背包，並從家中防災包取出 3 包乾糧與 3 瓶開水。」 |
| 爺爺（做出第一包乾糧時） | 「防災包裡的食物要選免烹煮、耐保存的，還要定期檢查保存期限。」 | 在原句後加：「防災包要放在家裡門口附近，平時多準備、定期換新，緊急的時候一手就能提走。」 |

**不要改的**：進城門檻 3 包／3 瓶（這是救援物資，不是居家儲備；若老師之後要調整，另行通知）。

### 3.6 存檔遷移（重要）

## 4. 設計決定的邏輯說明（供您遇到岔路時判斷）

### 4.1 為什麼地震章末不用「限時挑選」

地震地點是落石之城，不是住處。限時挑選只用在**人在住處、緊急狀況發生**時（第二章旅館大火、第三章海嘯警報等）。序章這一段教的是「遠行前自己打包」。

### 4.2 為什麼產出不直接進防災包

農田與乾糧製造機離爺爺家有一段路，直接進家中防災包不合情境。玩家需要「做好、帶回家、放進去」。

### 4.3 天數的遊戲內處理

| 概念 | 遊戲內做法 |
|---|---|
| 居家一週 | 防災包查看畫面顯示 x/7 目標，**不當作過關條件** |
| 避難包輕量 | 靠負重限制與取出到急救背包的過程體現 |
| 救援物資 | 進城仍是 3 包乾糧加 3 瓶開水 |

### 4.4 這次**刻意不做**的事

| 項目 | 原因 |
|---|---|
| 「限時挑選」小遊戲 | 序章用不到，第二章大火與第三章再做（見第 5 節） |
| 每半年檢查更新機制 | 先沿用現有過期機制，避免平衡問題 |
| 防災包內放手電筒、哨子、雨衣、收音機等 | 這些戶外裝備目前由急救背包使用（颱風、濃霧事件會檢查），先不動 |
| 哈姆立克知識卡更新 | 見第 7 節，另開章節處理 |

### 4.5 相容性底線

任何一位玩到一半的學生，更新後：進度不丟、物品不憑空消失、劇情與星數照舊。
