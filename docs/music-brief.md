# 急救王國 配樂委託說明（給 ChatGPT／作曲者）

> 用途：把這份文件的「給作曲者的指令」貼給 ChatGPT，只請它**作曲與輸出音檔**。接進遊戲（切換、淡入淡出、音量鈕）由專案端處理，作曲者不需要碰程式，也不需要 repo 或任何金鑰。
> 負責老師：黃雅蕾（蕾蕾）。整理日期：2026/10/01。

---

## 1. 分工

| 誰 | 做什麼 |
|---|---|
| ChatGPT（作曲） | 作曲，輸出可循環的音檔（mp3 或 ogg） |
| Claude Code（專案端） | 場景對應曲目、交叉淡入淡出、任務時換曲、音量與靜音鈕、偏好存檔、檔案進 repo、預載清單、手機載入量與測試 |
| 老師 | 聽過後確認曲風、循環接縫、音量，並確認授權可公開使用 |

## 2. 先確認 ChatGPT 能輸出什麼

| 方式 | 優點 | 缺點 |
|---|---|---|
| A. 直接輸出音檔（mp3／ogg） | 音色最好 | 要確認它真的能輸出可下載的音檔，以及授權 |
| B. 輸出 MIDI 或樂譜（音符資料） | 檔案很小，專案端可接現有的合成器 | 音色是電子合成 |
| C. 寫成 JS 合成程式 | 不需要音檔 | 與專案端已有的試聽版同一路線，沒有明顯優勢 |

優先順序：A → B。

## 3. 給作曲者的指令（整段貼給 ChatGPT）

```
我在做一個高中急救教學遊戲「急救王國」，需要背景音樂。請你只負責作曲與輸出音檔，不需要碰程式。

【世界觀】
曙光王國。百年前的救護騎士團不靠魔法，而是靠正確的急救知識守護人民。
主角是綠葉谷 17 歲少年，從爺爺那裡接下空背包，一路學習急救、幫助村民。

【遊戲風格】
薩爾達與符文工房的氛圍：溫暖、田園、探索感。不是恐怖或戰鬥遊戲。
對象是高中生，會在教室用 iPad 或手機玩，音樂不能干擾上課和對話。

【請先做這 5 首，每首都要能無縫循環（第 5 首除外）】
1. 綠葉村（主題曲）：輕快、溫暖，木吉他、魯特琴、長笛，約 80–90 BPM，大調，循環約 60–90 秒
2. 室內（爺爺的家、雜貨店）：柔和安靜，鋼琴或豎琴，約 70 BPM，循環約 45 秒
3. 森林與礦坑：神祕偏低沉，不要陰森，約 70 BPM，循環約 60 秒
4. 救援任務（地震、傷者）：緊張但不驚悚，節奏感較強，約 110 BPM，有急迫感但不制造恐慌，循環約 45 秒
5. 任務完成（短版，約 5–8 秒，不循環）：明亮的過關小號角

【技術規格】
- 格式：mp3，128 kbps 即可，每首小於 1 MB（要在手機和學校網路上載入）
- 循環點要無縫：結尾接回開頭不能有空白或爆音
- 音量一致：各首響度接近，避免切換時忽大忽小
- 不要有人聲，不要使用有版權的旋律，也不要模仿特定遊戲的曲子

【授權】
請確認這些音檔可以用在學校教學的公開網站上，並告訴我使用條款。

【請你回覆】
1. 你實際能輸出哪些格式（音檔、MIDI、樂譜？）
2. 每首的檔名、長度、BPM、調性
3. 你能否保證無縫循環；如果不能，請標出建議的循環起訖時間
```

## 4. 要附給作曲者的資料

不要給 repo、金鑰或學生資料。只給：

| 項目 | 內容 |
|---|---|
| 指令 | 第 3 節整段 |
| 世界觀 | 已包含在指令中 |
| 曲風參考 | 老師喜歡的遊戲或曲子**名稱**，只當風格參考，不要求照抄（老師自行補上：＿＿＿＿＿＿） |

## 5. 場景與曲目對應（專案端接入時使用）

| 曲目 | 檔名 | 對應場景 |
|---|---|---|
| 綠葉村 | `village.mp3` | village（綠葉村）、river（河谷）、plain（東方草原）、farm（農田） |
| 室內 | `indoor.mp3` | home（爺爺的家）、shop（雜貨店） |
| 森林與礦坑 | `forest_mine.mp3` | forest（南方森林）、mine_out、mine_in（礦坑） |
| 救援任務 | `rescue.mp3` | gate（落石之城）、ruin（地震後）救援期間 |
| 任務完成 | `clear.mp3` | 救援結算、章節完成（單次播放） |

之後新章節（第二章熔岩鍛造鎮、第三章港口藍堡）再另外補曲，格式與規格相同。第二章火災、第三章倒地分工等緊張情境可沿用 `rescue` 風格另做一首。

## 6. 拿回檔案後的流程

1. 老師先聽過：曲風是否合適、各首音量是否接近、循環接縫是否有破音、聽久了是否煩。
2. 音檔放到 `assets/music/`（檔名如上），並確認每首小於 1 MB。
3. 專案端接入：
   - 依場景切換曲目，交叉淡入淡出。
   - 設定選單加音樂開關與音量，偏好存在 localStorage。
   - **預設開或關由老師決定**：教室裡幾十台同時播放，建議預設關閉。
   - 瀏覽器規定要使用者互動後才能播放，所以從「開始」鈕觸發。
   - 離開頁面或螢幕鎖定時自動暫停。
   - 更新 `assets/manifest.json`，音檔改為按需載入，不放進啟動預載。
4. 測試：手機與 iPad 載入量、場景切換、靜音鈕、不影響存檔。

## 7. 注意事項

- **授權**：repo 與網站都是公開的。若作曲者提供的條款不允許公開網站使用，就不能放進專案。
- **備案**：專案端已有 `music` 分支的程式合成試聽版（`js/music.js`，目前只有綠葉村一首）。零授權問題、零檔案大小，但音色偏電子。聽過後可決定採用哪一種，或兩者並用（音檔載入失敗時退回合成）。
- **不隨意改動醫療內容**：配樂不涉及，但任務曲的氣氛請避免製造恐慌，遊戲訓練的是冷靜判斷。
