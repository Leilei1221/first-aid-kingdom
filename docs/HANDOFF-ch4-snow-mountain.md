## 4. 我（第三章這邊的 Claude）對雪山章的初步建議（供新對話參考，不是決定）
- **結構**：新章節資料包 `chapters/ch4/`（所有 id 前綴 `ch4_`）、有自己的 `region`（世界地圖釘點、營地當住處）。開放條件：完成第三章章末（`S.c.ch3_done`）＋尼泊爾商人見過（建議再要求集滿 3 片海圖碎片，這樣碎片才有用）。預設關閉，由老師端開放；先用 `draft` 只給預覽。
- **到達方式**：搭尼泊爾商人的船／交通工具到山腳；出發前有「裝備檢查」（類似防災包搬家的出發確認）：少了保暖衣物 → 雪山遇到失溫事件、嚴重時走進救援失敗；穿戴齊全則事件變輕。檢查要用 `S.c.ch3_e3.own`（目前只有紀錄）。
- **路線**：分高度的營地（山腳村 → 營地 1 → 營地 2 → 雪線 → 山屋），每個營地一個主題（保暖與補水、高山症、凍傷與雪盲、迷路與求救訊號、嚮導的救援分工）。重複使用既有已審核的知識卡（失溫、高山症、迷路、求救訊號），新增的醫療內容（凍傷、雪盲、雪崩應變等）一律先標 `draft`、列依據請老師審。
- **嚮導 帕桑**：像阿鹿那樣的同行 NPC，有好感度與「聊聊」話題；救援事件採「分工」（玩家做急救、嚮導做聯絡與搬運），延續第三章的分工與 CPR 教學。
- **完成後還有事做**（避免闖完就沒了）：山屋日常（每日的登山季求助、天氣窗口、補給與買賣）、嚮導訓練（可重複的挑戰）、之後再延伸國度。可參考第三章 E1～E3 的做法（公告板、每天一件事件、信譽、買賣、商人輪流）。
- **與裝備的連動**：登山包的格數與負重（山上要帶更多東西）、裝備欄（目前只有疊件外套、毛帽，其餘裝備只有擁有；雪山章可決定要不要讓褲子、手套、登山鞋也顯示在主角身上，需新增疊件圖或用整套裝扮）。
- **嚴重錯誤與救援失敗**：失溫已有情境可沿用；其他（高山症惡化、凍傷、迷路過夜）需要老師提供說明文字，請在規劃階段就列出清單問老師。
