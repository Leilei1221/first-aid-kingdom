## 3. 完成後的日常（避免闖完就沒了）
沿用 E1～E3 模式，狀態記在 `S.c.ch4_*`，不新增頂層欄位。
- **山屋公告板**：每天輪一件登山求助事件（凍傷、雪盲、高山症、迷路、失溫），草稿階段先做 5 件，之後可擴充。
- **天氣窗口**：每天預報「適合上山／風雪大不宜」，不宜時只能留在山屋做補給與訓練（與核心天氣引擎的接法待實作時評估，原則是不新增隨機天災）。
- **補給與買賣**：山屋小店（暖暖包、毛襪、熱飲）、帕桑收購藥品與繃帶（沿用 `e3.json` 的 `SELL`）。
- **嚮導訓練**：可重複的分工挑戰，沿用章末演練題庫的隨機組合。
- **嚮導信譽**：處理求助、完成訓練累積，稱號見習 → 正式 → 隊長；達標解鎖新營地事件或新商品。
- 與核心每日任務／簽到的關係：沿用核心，雪山章不另做第二套；「處理一次事件」可把山屋求助算進去（需核對 `daily` 掛接點，實作時再確認）。
