# 雪嶺「抉擇與求生」劇情規劃（草案，2026-10-13，只是規劃，還沒寫程式）

老師的想法（2026-10-13）：雪山關卡要多一些不一樣的劇情——上山前看氣象預報圖、自己判斷要不要上山（上不上都可以，但都可能遇到暴風雪或山崩）；在營地或山屋遇到暴風雪、窗戶破掉，要用打火石生火、管理有限的乾糧與水、用到保暖衣與保暖毯（裝備才有意義）；可能被困山屋 2～3 天，要野外求生與處置背包物品；活不下去或卡關就退回雪山第一天；也可以做迷路、指南針判定、風向。

## 0. 現有可以直接用的東西（不用重做）
- 天氣：`daily.js` 的雪嶺天氣窗口（每 4 天一次暴風雪、可預報）、核心 `wxNext` 預報機制。
- 裝備：`GEAR`（護目鏡、保暖襪、保暖毯、頭燈、登山包）已有「少耗體力」的作用；章節狀態 `S.c.ch4`。
- 打火石：核心已有（`S.mat.flint`，目前只有礦坑 30% 掉落、營火露營要木材 3）。
- 知識卡（已審）：失溫、高山症、迷路、求救訊號、營火；題目與卡片都在 `chapters/ch4`、`content`。
- 救援失敗機制 `rescueFail`（現有知識卡＋扣救援費＋送回山腳村）。

## 1. 整體結構：「上山前判斷」→「事件」→「求生」→「成功或退回」
```
山腳村：看氣象圖（判斷）
   ├─ 選「等一天」：花旅店錢，換一個較好的天氣窗口（最多等 2 天，之後山況不會再變好）
   └─ 選「現在出發」或「勉強出發」
        ↓（天氣是固定算出來的，不是抽籤，學生可以重試也會得到一樣的結果）
   路上遇到事件（落石／迷路／暴風雪），每個事件有 2～3 個「抉擇點」
        ↓
   營地 2 或山屋：暴風雪困住 1～3 天（求生玩法）
        ↓
   撐過去 → 繼續第 4、5 節與章末；撐不過 → 退回（見第 5 節）
```
原則：**沒有「標準答案路線」**。選擇出發或等待都合理，差別是會遇到什麼、準備夠不夠；失敗要能讓學生看到「是哪個決定、哪件裝備造成的」。

## 2. 上山前的氣象判斷（山腳村）
- 新互動：山腳村旅店門口的「氣象公告」，顯示 3 天預報圖（**要新圖**：一張像氣象署的簡化天氣圖＋三天風向／雲量／降雪圖示）。
- 判斷題（學生讀圖回答，題目是新的、要老師審）：看出哪一天風大、哪一天有降雪、什麼時候是「窗口」。回答影響的是「提示給多少」，不是對錯擋關。
- 三種選擇：**現在出發**（這幾天內有暴風雪，會遇到事件）／**等一天**（付旅店費，下一天預報較好）／**勉強出發**（看得出有風險仍然上去：多一個事件但有額外報酬？待老師決定）。
- 預報本身做成「天氣 + 風向」資料（例：風從東北來），風向在後面的生火與避風題會用到。

## 3. 路上的事件（每次旅程由天氣決定遇到哪一個）
| 事件 | 地點 | 抉擇與考驗 | 對應現有知識 |
|---|---|---|---|
| 落石／山崩 | 營地 1→2 的小徑 | 聽到上方落石聲：停下、找掩護、等安靜後再走、繞路或折返。**不放雪崩救援**（老師 2026-10-10 決定過「雪崩不放」，這裡只做一般落石山崩，請老師確認可以） | 新題（老師審） |
| 迷路／白茫茫（whiteout） | 雪線→山屋 | 能見度很低：STOP 原則（停、想、觀察、計畫）、用哨子或手電筒求救、用**指南針與地圖判斷方向**（見第 4 節）、不要亂走 | 迷路卡、求救卡（已審）＋新題 |
| 暴風雪 | 營地 2 或山屋 | 進入第 3 節的求生玩法 | 失溫卡、營火卡＋新題 |

## 4. 求生玩法（被暴風雪困在山屋／營地 1～3 天）
**情境**：暴風雪來了，山屋窗戶被風吹破（也可以是營地 2 的帳篷被吹壞），救援要等 1～3 天才進得來（天數由預報決定，不是亂數）。
**資源**：把玩家帶的東西都變成資源，**買的裝備才有意義**：
| 資源 | 來源 | 用途 |
|---|---|---|
| 乾糧、開水 | 背包 | 每天要吃喝；不夠要節約（分配）。雪可以化水但要燒火（花燃料） |
| 打火石＋木柴 | 背包／山屋存柴 | 生火取暖與化雪；有限，要決定先用在哪裡 |
| 保暖衣、保暖毯 | 背包 | 保暖值；毯子可以給受寒的人 |
| 頭燈、手電筒、哨子 | 背包 | 夜間行動、求救 |
| 其他背包物品 | 背包 | 例如雨衣可以擋破窗，哨子求救 |

**回合**：每天白天／夜晚各一次行動（共 2～3 次），畫面上方顯示「體溫（保暖）」、乾糧、水、柴火。例如：
- 用什麼擋住破窗（雨衣、帳篷布、睡墊）？風是從哪邊吹來？（風向題）
- 在哪裡生火？（靠近破窗？室內通風怎麼辦？——一氧化碳風險是真的安全重點，**需要老師審來源**）
- 哪些人要優先保暖？毯子給誰？大家擠在一起還是分開？
- 乾糧水怎麼分？要不要化雪？吃什麼時候？
- 要不要冒險出去求救？（正確答案通常是留在避難處、用訊號求救）
**結果**：每天結算保暖值、水和食物。保暖值或水撐到救援抵達就成功；撐不到就失敗。
第 2～3 天加入第二個壓力（有人體溫過低、有人高山症），可以用現有的處置題。

## 5. 失敗與退回（老師的規則）
老師說的是：活不下去或卡關 → **退回雪山第一天，所有遊戲進度回到第一天**。這和現在的「嚴重錯誤 → 扣救援費、送回山腳村」不同，要老師確認細節：
1. **退回到哪裡？** 建議：旅程開始時（到山腳村第一天）自動存一份快照；失敗就回到那份快照（天數、金幣、背包、位置、第 1～5 節的進度都回去）。
2. **知識卡要保留嗎？** 建議保留（學習成果不該被收走），題目星數與第 1～5 節進度才重來。
3. **要不要扣救援費？** 建議不再重複扣（已經整趟重來了）。
4. **重來幾次？** 建議不限次數，並在失敗畫面用現有知識卡說明「是哪一個決定出了問題」。
5. **班級學生負擔**：整趟重來對課堂時間不友善。建議加「嚮導訓練」版（只記錄、不退回），讓老師可以選嚴格版或練習版。

## 7. 建議的做法與分階段
**建議**：先做「氣象判斷＋山屋暴風雪求生」這一條主線（最符合老師的想法，也最能讓裝備有意義），迷路與指南針、落石放第二階段；快照與退回要在第一階段就做好。
1. **G1** 資料與快照：天氣＋風向資料、旅程快照與退回、測試。
2. **G2** 上山前氣象判斷（含新圖）。
3. **G3** 山屋暴風雪求生（資源回合、1～3 天、失敗退回）。
4. **G4** 迷路與指南針、風向題。
5. **G5** 落石事件、老師端顯示、整體平衡與 51 情境比對。
每階段先給老師看題目與敘述草稿，審過才寫入；每階段獨立提交附測試；推送等老師說「推」。
