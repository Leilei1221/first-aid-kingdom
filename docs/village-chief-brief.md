# 新角色「村長」形象說明（給生圖的 Claude Chat／繪圖工具）

> 用途：請依下列說明設計「綠葉村村長」的**全身立繪**與**對話頭像**，風格要與遊戲現有角色一致。
> 村長在遊戲裡的任務：山洪或地震災後，指揮調度**救災物資發放**（乾糧、開水、打火石），並提醒大家「應急不是長期補給，平時要有自己的防災包」。

## 1. 世界觀（給設計者看的背景）

「急救王國」是花蓮高中基礎急救課程的教學遊戲。世界叫曙光王國，百年前的救護騎士團不靠魔法，靠正確的急救知識與三件神器守護人民。主角是綠葉谷 17 歲少年，爺爺是最後一任騎士團團長。綠葉村是主角生活的村莊，村長是村裡負責統籌災後救援與物資的人。

## 2. 角色設定

| 項目 | 內容 |
|---|---|
| 名稱 | 村長（遊戲內顯示「村長」）；角色代號 `chief` |
| 年齡與性別 | 約 55–60 歲的**女性**（沉穩、有條理、見過大風浪）。老師已確認以女性為預設 |
| 登場章節 | **只在序章（綠葉村）**。第三章港口藍堡有自己的角色，不使用這位村長 |
| 個性 | 冷靜、有條理、務實、有溫度。災難時不慌，三兩句話就能分配好工作。不是嚴厲官僚，是讓人安心的長輩 |
| 氣質關鍵字 | 可靠、鄉土、領導力、照顧人 |
| 身分 | 綠葉村的民選村長，也曾是救護騎士團的後勤志工 |

## 3. 外觀建議

- **髮型**：灰白或深棕夾雜銀絲，利落的低盤髮或綁在腦後，不要華麗。
- **服裝**：鄉村與騎士團後勤的混合。耐穿的深綠或橄欖綠長版外套或披風，內搭米白襯衫與皮革腰帶，腰間掛一串**鑰匙**與一本**登記冊或名冊**（象徵倉庫與物資管理）。
- **配色**：以**綠、米白、棕**為主，與綠葉村和騎士團的色調一致；可點綴一點金色（扣環或徽章）。避免紅色為主色。
- **徽章**：胸前或披風扣上**綠底白十字**的急救徽章。
  - **這點很重要**：遊戲所有急救標誌一律使用**綠底白十字**，**不要使用紅十字**。
- **手持物**：一個木製或皮革的**物資清單板**，或一只小提籠。**不要拿武器**。
  - **清單板上只能有空白或抽象的線條，不可以有任何文字或數字**，否則生圖常出現亂碼文字。
- **與現有角色的配色區分**：爺爺是紅色披風與棕色，城堡守衛是藍色與銀色鎧甲。村長用**橄欖綠＋米白**，不要用紅色或藍色為主色，才容易一眼分辨。
- **姿態**：站姿挺直、一手持清單、另一手微微抬起像在指揮，表情沉穩帶一點關切的微笑。

## 4. 風格要求（請與現有角色一致）

- 日系奇幻遊戲角色插畫風：線條清楚、上色細緻、有布料與金屬的質感，有類似薩爾達與符文工房的溫暖感。
- 柔和的自然光，不要太強烈的陰影。
- 參考：專案中的 `grandpa.webp`（爺爺）、`guard.webp`（城堡守衛）、`cook.webp`（廚娘）。
- **不要寫實照片風**，不要 3D 渲染風，不要卡通 Q 版。

## 5. 要交付的兩張圖

### A. 全身立繪 `chief.webp`

| 項目 | 規格 |
|---|---|
| 構圖 | **全身**，正面略帶四分之三角度，頭到腳完整入鏡，不裁切 |
| 背景 | **純平坦的中灰色背景**（例如 #808080，不要漸層、不要陰影、不要地面），方便專案端去背。生圖工具通常無法直接輸出真正的透明，與其勉強要求透明，不如用單色背景讓後製去背 |
| 比例 | 寬高比約 **0.65 : 1**（現有角色約 340 × 520 像素，例如 335×520、342×520）。請盡量做成同樣比例 |
| 尺寸 | 全身高度約 **1000 像素以上**（我們會縮小成 520），寬度依比例。若與頭像放在同一張圖，可用 **1536×1024**：左邊全身、右邊肩上頭像，專案端會裁切 |
| 格式 | PNG，之後由專案端去背並轉成 WebP |
| 其他 | 腳下留一點空間，不要有地面或投影（遊戲會自己加陰影） |

### B. 對話頭像 `chief_face.webp`

| 項目 | 規格 |
|---|---|
| 構圖 | **臉部與肩膀**的半身特寫，臉置中，眼睛在畫面上半部 |
| 尺寸 | **正方形**，至少 320 × 320 像素（我們會縮成 160 × 160）。放在同一張圖時，頭像取右側約 320×320 的區域 |
| 背景 | 同樣用**純平坦的中灰色背景**，由專案端去背 |
| 表情 | 沉穩、溫和、略帶笑意 |
| 一致性 | 髮型、服裝顏色、徽章要與全身立繪一致 |

## 7. 交付與檢查

1. 請把全身立繪與頭像各給一張定稿。若設計了多個版本，標示哪一張是定稿。
2. 檔名：`chief.png`、`chief_face.png`。
3. **自我檢查清單**：
   - [ ] 全身完整，沒有被裁到。
   - [ ] 背景是純平坦的灰色，沒有漸層與陰影。
   - [ ] 清單板上沒有文字或數字。
   - [ ] 配色不是紅色或藍色為主（與爺爺、守衛區分）。
   - [ ] 急救徽章是**綠底白十字**，沒有紅十字。
   - [ ] 沒有拿武器。
   - [ ] 全身與頭像的髮型、服裝、徽章一致。
   - [ ] 風格與爺爺、守衛等角色接近。
4. 收到圖後，專案端會：轉成 WebP、放進 `assets/`、補上角色資料與對話。對話文字會另外擬稿給老師審核。
