## 1. 為什麼現在「闖完就沒了」

- 第三章的結構是「依序練習第 1～4 節 → 章末演練 → 完成」，完成後港口沒有理由再回來。
- 第一章有農田、野採、商店、製作、自動化、好感度，每天都有事可做；第二章與第三章沒有這一層。
- 解法：不是把關卡拉長，而是給港口一個**每天會變的日常迴圈**，並把急救知識藏在日常事件裡（有需求才學，而不是被考）。

## 2. 藍堡的日常迴圈（建議）

早上起床 → 看**港口公告板**（今天有哪些求助、哪艘商船靠岸）→ 釣魚／處理求助／交易 → 賣漁獲、買用品 → 回旅店睡覺（建立存檔點）。

| 項目 | 內容 | 為什麼黏 |
|---|---|---|
| 港口公告板 | 每天列 1～2 件事：求助、商船到港、釣魚提醒 | 玩家每天有明確目標 |
| 港口求助事件 | 海洋傷害 4 種起頭，之後可再加（噎到、中暑、落水打 118） | 日常重複但情境會變，知識卡慢慢收集 |
| 釣魚與買賣 | 見第 4 節 | 賺錢、補體力、學保育 |
| 各國商人 | 商船每隔幾天靠岸一次，各國特產與雙語對話 | 有收集感，也是世界延伸的伏筆 |
| 港口信譽 | 處理求助、放生小魚累積；達標解鎖新釣點、新商品 | 長線目標，不是一次打完 |
| 燈塔 | 目前是空場景：之後作為信譽達標的獎勵地點（夜間事件、新釣點） | 讓已有的場景有用處 |

故事主線建議（讓第三章有「之後」）：救生員（爺爺的老朋友）想把港口辦成「安全港」，章末演練完成後，玩家成為港口安全志工，用信譽升級（見習 → 正式 → 隊長）。心跳之匣是起點，不是終點。

### 3.1 藍環章魚咬傷（依澳洲指引；國內沒有教材）
- 情境：小孩在潮池撿到一隻有藍色環紋的小章魚，手臂被咬了，說嘴唇和舌頭發麻、胸口緊緊的。
- 題目 1：現場最優先該怎麼做？
  - A 抓起章魚讓大家看清楚是什麼
  - B 讓傷者坐下、保持不動、安撫他，立刻打 119 求救 ← 正解
  - C 用嘴把傷口的毒液吸出來
- 題目 2（手臂被咬）：求救之後，傷口怎麼處理？
  - A 在傷口上方用細繩綁緊，阻斷血流
  - B 用寬的彈性繃帶從咬傷處往肢體包覆、固定住，不要讓手臂亂動（加壓固定）← 正解
  - C 把手臂浸在冰水裡
- 題目 3（連到第三章）：傷者忽然沒有反應、也沒有正常呼吸，怎麼辦？ → 立刻開始 CPR 並請人拿 AED、持續到救護人員接手（沿用第三章已審核內容）。
- 解說（草稿）：藍環章魚的唾液含神經毒素，咬傷常常不痛，但會讓嘴、臉、頸發麻、胸口緊、呼吸困難，嚴重時呼吸會停止；沒有解毒劑，重點是儘快求救、讓傷者保持不動，並隨時準備人工呼吸或 CPR，直到毒性消退或救護人員接手。平常不要徒手碰有藍色環紋的章魚，翻潮池的石頭也要小心。
- 依據：澳洲復甦委員會（加壓固定、人工呼吸）、澳洲各州衛生單位與聖約翰救護的急救說明。細節見文件最後的資料來源。**這是國外指引，台灣沒有對應教材，請老師決定是否採用。**

### 3.2 水母螫傷（只用海水沖洗，不教醋與熱水；老師已決定）
- 情境：遊客在淺灘被水母纏到，手臂紅腫、很痛。
- 題目：被水母螫到後，第一步怎麼做？
  - A 用淡水用力沖洗、搓揉傷口
  - B 離開水域，小心移除黏附的觸手（戴手套，或用卡片、鑷子，不用手直接抓），用海水沖洗，不要搓 ← 正解
  - C 用尿液沖
- 追問：什麼情況要立刻求救？ → 呼吸困難、臉或喉嚨腫、胸痛、頭暈或昏倒、疼痛很久不退或範圍很大。
- 解說（草稿）：淡水和搓揉可能讓殘留的刺細胞釋放更多毒液；用海水沖洗、移除觸手即可。出現全身症狀要立刻求救。

### 3.3 岩石（牡蠣殼）割傷
- 情境：玩家或路人在礁岩上被牡蠣殼割出一道傷口，流血，傷口泡過海水、沾了砂。
- 題目 1：流血時，第一步？ → 用乾淨的布直接加壓止血 ← 正解（沿用第一章外出血已審核內容）。
- 題目 2：血止住後，傷口泡過海水、沾了砂，怎麼處理？ → 用大量乾淨的水沖洗，蓋上乾淨敷料，之後留意紅腫、發燒；傷口深、很髒或疫苗很久沒打，要就醫 ← 正解（連到破傷風與下一種弧菌）。

### 3.4 海洋弧菌感染（重點：一定要先就醫，要特別強調）
- 情境：漁夫手上有小傷口，昨天下海、又處理生魚；今天傷口周圍快速紅腫、發熱、起水泡，還發燒，他覺得「小傷口，擦擦藥就好」。
- 題目：該怎麼辦？
  - A 擦藥膏在家觀察幾天
  - B 立刻就醫，並告訴醫師傷口接觸過海水或生海鮮 ← 正解
  - C 再下海泡鹽水消毒
- 加強提示（答完後的大字，不是只放在解說裡）：**「傷口碰過海水或生海鮮，紅腫、發熱、起水泡、發燒，一定要先就醫，不要自己在家處理、不要等。」**
- 解說（草稿）：海洋弧菌感染可能在一兩天內快速惡化，嚴重時危及生命，所以一定要先就醫。預防：傷口不要碰海水、處理海鮮戴手套、海鮮煮熟再吃。（肝病、糖尿病等較容易嚴重，只放一句，不是重點。）
- 依據：美國疾管署對創傷性弧菌感染的說明（短潛伏期、可能很快變重、需儘快治療）。**台灣疾管署原文請老師核對。**

> 這四個事件與第三章的關係：藍環章魚用到 CPR，割傷延伸止血，弧菌延伸「就醫時機」，水母是新知識。

## 4. 釣魚與漁獲買賣（含海洋保育）

### 4.1 玩法
- 地點：碼頭、礁岩（礁岩多一點魚，但也有割傷與潮池危險）。道具：釣竿（商店買或製作）。
- 一次釣魚：簡單的時機小遊戲（拉起的瞬間按下），釣到後出現「魚尺」。
- 釣到後的選擇：**留下／放回**。
  - 低於魚尺線的小魚 → 放回（拿「港口信譽」，不賺錢）。留下也能賣，但會被救生員或攤販提醒，信譽不增加（不處罰到難玩）。
  - 保育類動物（例如海龜、鯨豚這類，名單待老師核對）→ 必須放回，並看到保育說明；若選擇留下，攤販不收，救生員說明規定（不扣大額金錢，教學為主，細節待老師決定）。
  - 剛好的大小 → 留下、賣給市集或自己煮來吃（補體力）。
- 漁具：商人兜售「便宜大網」「流刺網」時，玩家選拒絕才是對的，附說明：這類漁具會一次撈起所有東西，包括小魚與保育類動物，不適用。
- 魚尺數字是**遊戲參數**，不是真實法規數字（和第三章遊戲參數一樣放在 `balance.json`，不寫真實公分數）。
- 食用：魚要煮熟才吃（連到弧菌）。生吃會顯示風險提示（不處罰）。

### 4.2 保育與漁具（我查到的資料，待老師核對後定稿）
- **遊戲裡的保育類（先放 4 類）**：海龜（蠵龜科所有種，如綠蠵龜、玳瑁）、鯨豚（鯨目所有種）、鯨鯊、鬼蝠魟（蝠鱝）。依據：海洋委員會《海洋保育類野生動物名錄》，鯨鯊與鬼蝠魟於 2020 年改列瀕臨絕種保育類；《野生動物保育法》禁止騷擾、虐待、獵捕、買賣、持有保育類野生動物。珊瑚與硨磲貝之後可補。
- **漁具**：流刺網會把網到的大小魚、海龜、鯨豚、海鳥一起纏住（混獲），漁業署與保育團體都在討論。台灣沿近海的管制多由縣市公告，例如花蓮縣在部分水域劃定近岸禁用範圍；遊戲裡不放真實距離與罰款數字，只教「流刺網一次纏住所有東西、不分大小與保育類，不適用，很多地方限制或禁止」。**請老師決定這樣的說法夠不夠。**
- **知識卡（草稿，待審）**：`size`（小魚放回，長大了才能繁殖）、`protected`（保育類不能抓、不能買賣）、`gear`（為什麼流刺網不適用）、`cook`（海鮮要煮熟）。文字我擬稿後請老師審。

### 4.3 買賣
- 港口市集新增攤販（買賣漁獲、賣用品與食材）。價格都是遊戲參數。
- 賣漁獲的錢、補體力的食物，會和第三章完成後的商店體能補給（老師 2026-10-07 已決定）形成同一條經濟線。

### 5.1 尼泊爾商人：販售登山裝備（老師 2026-10-08 建議）

道理：之後雪山章的主角不能憑空變出防寒衣物，所以裝備要在第三章先靠買賣取得；最後商人可以邀請同行、當嚮導與救援，但裝備仍然是用買的（或用東西交換）。

- **賣的東西（草稿，名稱與分類請老師調整）**：防寒外套、保暖帽、防寒褲、手套、登山靴、保暖襪、護目鏡、暖暖包、保暖毯、頭燈。價格高於一般用品，要靠釣魚、賣漁獲、處理求助的收入慢慢存，這樣第三章的日常（E1、E2）就有長線目的，而不是賺了沒處花。
- **交換**：除了付金幣，商人也收漁獲、藥品、繃帶（像上表「買」的欄位），可以用東西換部分裝備。
- **怎麼存**：背包現在只有 14 格、有負重限制，衣物不應該擠掉急救用品。建議新增「穿著與裝備」一欄（頭、身體、腿、手、腳），買了就穿上或存起來，不佔背包格數；存放在 `S.c`，不新增頂層欄位。
- **雪山章怎麼用**：出發前有「裝備檢查」（類似防災包搬家的出發確認）：少了保暖衣物會在雪山遇到失溫事件、嚴重時走進救援失敗流程；穿戴齊全則事件變輕。細節等雪山章規劃時再訂。
- **教學重點（草稿，待審）**：多層次穿著（吸濕排汗、保暖、防風防水）、手腳與頭部保暖、濕了要換。這些是醫療與安全內容，要老師審；現有知識卡「失溫」（`hypothermia`）可以直接連上。
- 這一項屬於 E3（商人）的一部分；登山裝備只先做「買、存、顯示」，不影響第三章上線。
