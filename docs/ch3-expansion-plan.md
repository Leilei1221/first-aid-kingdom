## 1. 為什麼現在「闖完就沒了」

- 第三章的結構是「依序練習第 1～4 節 → 章末演練 → 完成」，完成後港口沒有理由再回來。
- 第一章有農田、野採、商店、製作、自動化、好感度，每天都有事可做；第二章與第三章沒有這一層。
- 解法：不是把關卡拉長，而是給港口一個**每天會變的日常迴圈**，並把急救知識藏在日常事件裡（有需求才學，而不是被考）。

### 3.1 藍環章魚咬傷
- 情境：小孩在潮池撿到一隻有藍色環紋的小章魚，被咬了，說嘴唇和手發麻。
- 題目：被藍環章魚咬傷，現場最優先該怎麼做？
  - A 抓起章魚讓大家看清楚是什麼
  - B 讓傷者安靜休息、不要亂動，立刻求救（119），並一直注意呼吸 ← 正解
  - C 用嘴把傷口的毒液吸出來
- 解說（草稿）：藍環章魚的唾液有神經毒素，咬傷可能很快造成麻痺和呼吸困難，沒有一般現場可做的解毒方法，重點是儘快求救和守住呼吸。不要徒手碰、翻潮池的石頭和章魚。
- 追問（連到第三章）：傷者忽然沒有反應、也沒有正常呼吸，怎麼做？ → 立刻開始 CPR 並請人拿 AED（沿用第三章已審核內容）。
- 待老師確認：加壓固定繃帶要不要教（國外指引有，台灣指引我沒核對，目前不放）；打 119 或 118（海巡）的分流（沿用第 4 節已審核的專線說明）。

### 3.2 水母螫傷
- 情境：游客在淺灘被水母纏到，手臂紅腫、很痛。
- 題目：被水母螫到後，第一步怎麼做？
  - A 用淡水用力沖洗、搓揉傷口
  - B 離開水域，小心移除黏附的觸手（戴手套或用鑷子、卡片，不用手直接抓），用海水沖洗 ← 正解
  - C 用尿液沖
- 解說（草稿）：淡水和搓揉可能讓刺細胞釋放更多毒液，所以用海水沖洗、不要搓。若有呼吸困難、胸痛、全身不適，要立刻求救。
- 待老師確認：醋與熱水處理（不同水母的建議不同，我沒有核對台灣指引，目前不放）；是否用「箱形水母」這類名稱。

### 3.3 岩石（牡蠣殼）割傷
- 情境：玩家或路人在礁岩上被牡蠣殼割出一道傷口，流血，傷口泡過海水、沾了砂。
- 題目 1：流血時，第一步？ → 用乾淨的布直接加壓止血 ← 正解（沿用第一章外出血已審核內容）。
- 題目 2：血止住後，傷口泡過海水、沾了砂，怎麼處理？ → 用大量乾淨的水沖洗，蓋上乾淨敷料，之後留意紅腫、發燒；傷口深、很髒或疫苗很久沒打，要就醫 ← 正解（連到破傷風與下一種弧菌）。

### 3.4 海洋弧菌感染
- 情境：漁夫手上有小傷口，昨天下海、又處理生魚，今天傷口周圍快速紅腫、發熱、起水泡，還發燒。他有肝病。
- 題目：該怎麼辦？
  - A 擦藥膏在家觀察幾天
  - B 立刻就醫，告訴醫師傷口接觸過海水或生海鮮 ← 正解
  - C 再下海泡鹽水消毒
- 解說（草稿）：弧菌在溫暖的海水中比較多，傷口接觸海水或處理生鮮可能感染；肝病、糖尿病或免疫力較低的人更容易惡化，要儘快就醫。預防：傷口別碰海水、處理海鮮戴手套、海鮮要煮熟。
- 待老師確認：「溫暖海水」「肝病、糖尿病」的說法請核對衛福部／疾管署原文。

> 這四個事件與第三章的關係：藍環章魚用到 CPR，割傷延伸止血，弧菌延伸「就醫時機」，水母是新知識。

## 4. 釣魚與漁獲買賣（含海洋保育）

### 4.1 玩法
- 地點：碼頭、礁岩（礁岩多一點魚，但也有割傷與潮池危險）。道具：釣竿（商店買或製作）。
- 一次釣魚：簡單的時機小遊戲（拉起的瞬間按下），釣到後出現「魚尺」。
- 釣到後的選擇：**留下／放回**。
  - 低於魚尺線的小魚 → 放回（拿「港口信譽」，不賺錢）。留下也能賣，但會被救生員或攤販提醒，信譽不增加（不處罰到難玩）。
  - 保育類動物（例如海龜、鯨豚這類，名單待老師核對）→ 必須放回，並看到保育說明；若選擇留下，攤販不收，救生員說明規定（不扣大額金錢，教學為主，細節待老師決定）。
  - 剛好的大小 → 留下、賣給市集或自己煮來吃（補體力）。
- 漁具：商人兜售「便宜大網」「流刺網」時，玩家選拒絕才是對的，附說明：這類漁具會一次撈起所有東西，包括小魚與保育類動物，不適用。
- 魚尺數字是**遊戲參數**，不是真實法規數字（和第三章遊戲參數一樣放在 `balance.json`，不寫真實公分數）。
- 食用：魚要煮熟才吃（連到弧菌）。生吃會顯示風險提示（不處罰）。

### 4.2 保育知識卡（草稿，待審）
`size`（大魚小魚：留下長大的才能繁殖）、`protected`（保育類不能抓、不能買賣）、`gear`（為什麼流刺網不適用）、`cook`（海鮮要煮熟）。內容我會依老師的口吻擬稿，保育類名單與漁具規範請老師核對原文。

### 4.3 買賣
- 港口市集新增攤販（買賣漁獲、賣用品與食材）。價格都是遊戲參數。
- 賣漁獲的錢、補體力的食物，會和第三章完成後的商店體能補給（老師 2026-10-07 已決定）形成同一條經濟線。
