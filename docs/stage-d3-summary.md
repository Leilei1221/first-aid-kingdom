# 階段 D3「第二章（熔岩鍛造鎮）＋渡海」摘要（請老師確認後才動工）

依工作守則：動工前先給摘要。**沒有任何程式已經改動。** 規格來源：V3 `HANDOFF.md` 第 11 節、V3.1（旅館二樓、設備檢查、砂輪機）、V3.2（渡海航線）；原型程式 `~/Projects/first-aid-kingdom-v3-spec/v3.2/src/script.js` 只當對照，**不覆蓋**現有程式。

## 目標

第二章成為第一份真正的「章節資料包」：場景、角色、對話、知識卡、事件都放在 `chapters/ch2/`，預設**關閉**；序章在章節關閉時玩起來**完全不變**。渡海把綠葉谷與鍛造鎮連起來。

## 我發現的重要事實

V3 的第二章**不是資料，而是寫死在 `script.js` 的程式**：約 800 行（`talk2`、`goal2`、`news2`、`check`、`bigFire`、`grinder`、`forge`、`warehouse`、`innRoom`、`fireReport`、`captTalk`、`voyageMeal`、`voyageSleep`、`stormy` 等），對話文字、題目、解說夾在程式裡。所以 D3 的主要工作是：

1. 把對話、題目、解說**逐字**搬進 `chapters/ch2/dialogues.json`、`events.json`、`cards.json`（不改寫任何醫療文字；與 V3 逐字比對）。
2. 把玩法程式（沖水計時 `coolGame`、步驟排序 `orderQuiz`、滅火器 `extGame`、壓力表 `check`／`gaugeSvg`、渡海）整理成章節程式，掛到 D1／D2 的框架上。

### 與原摘要不同的地方（請老師知道）

1. **對話與題目文字留在 `chapters/ch2/chapter.js`，沒有拆進 JSON。** 這些文字夾在判斷程式裡，硬拆會增加出錯機會。我用腳本逐段比對：292 段中文只有 7 段不在 V3.2 原型裡，而且全是我寫的程式註解，所以**玩家看得到的文字與 V3.2 逐字相同**。審核第二章文字請讀 `chapters/ch2/chapter.js`。知識卡仍在 `cards.json`。
2. **V3.2 原型的一個錯誤已修正**：漁港與碼頭的「搭船」互動點與村口委託板同名，原型裡按下去會打開委託板、船長買票只能靠跟船長說話。我把它改成專屬的「搭船」動作。
3. **檢查點座標用 V3.2 程式裡的資料**（`content/chapter2.json` 是舊版，旅館二樓的兩個檢查點座標會落在走不到的牆上）。
4. **停航**：`stormy()` 先永遠回傳「否」，D4 接天氣。
5. 昏倒原因 `exhaust`（V3 新增的專屬說明）屬 D4 的體力／天災部分，沒有移植；第二章昏倒用現有的兩種說明，醒在旅館二樓。
6. 第二章的 3 張新知識卡（穿救生衣、暈船、落水與仰漂）與渡海數字：老師 2026-10-02 回覆「OK 確認好了」，按確認處理。若實際尚未逐字審，請告訴我，我改標待審。
