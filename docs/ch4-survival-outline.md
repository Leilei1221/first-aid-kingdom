## 0. 規則回顧（老師已決定）
- 嚴重錯誤（標 `sev`）＝請救援：扣救援費 200、送回山腳村（現有知識卡顯示在失敗畫面）。嚮導訓練版只記錄。
- 「勉強出發」不給獎勵。落石只做一般落石，要有前兆、讓玩家先預測。
- 既有已審知識卡可以重用，不新增：失溫（`hypothermia`）、高山症（`altitude`）、迷路（`lost`）、求救訊號（`signal`）、營火（`campfire`）。**新增的知識卡只有第 6 節列的 4 張草稿，等老師決定要不要。**

| W2 | 山腳村現在 5°C，山屋一定也是 5°C 嗎？ | ✓ 不會，山上通常更冷，而且有風會覺得更冷／會，溫度一樣／山上比較暖 | 越往上越冷，風會讓身體散熱更快。⚠ 來源把「每上升 100 公尺降 1°C」當估計，標準大氣約 0.65°C，所以遊戲只講「更冷」，不放數字。 | 否 |
| W3 | 出發前，你和嚮導要先決定什麼？ | ✓ 什麼時候、遇到什麼情況就掉頭下山／走到哪算哪／別人都上去我也上去 | 事先講好「回頭的條件」，天氣比預報更糟時就比較容易下決定。 | 否 |

## 4. 山屋暴風雪（求生，被困 1～3 天）
**情境**：山屋的窗戶被風吹破，雪灌進來；通往山下的路被封，救援要等 1～3 天（由預報決定）。

資源：保暖值（0～100）、乾糧、開水、打火石、木柴、保暖衣、保暖毯、雨衣、哨子、頭燈、手電筒。每天白天與夜晚各一次行動。**資源數字是遊戲平衡，不是醫學數字**，我會在做程式時定，給老師看。

| # | 題目（行動） | 選項（✓ 正解） | 解說（草稿） | 嚴重？ |
|---|---|---|---|---|
| S1 | 窗戶破了，風雪灌進來。用什麼擋？ | ✓ 用雨衣、帳篷布或睡墊把破窗蓋起來，固定好；人離窗口遠一點／站在窗邊看外面／什麼都不用，反正有生火 | 先擋風，才有辦法保暖。人也不要待在風直接灌進來的位置。⚠ 這是一般常識。 | 否 |
| S2 | （風向）風從西邊吹來，要把擋風的東西放在哪？（做成簡單的示意圖，選位置） | ✓ 放在風吹來的那一側，人在後面（背風處）／放在風吹去的那一側／不用放 | 擋在風和人之間，人躲在背風處，體溫比較不會被風帶走。⚠ 山坡背風側可能有積雪堆，這是雪崩的內容，**這裡不放**，只講室內與避難處的擋風。 | 否 |
| S3 | 要生火取暖，要怎麼做？ | ✓ 用打火石生火，火邊不放易燃物，房間一定要留通風口，不要在火還燒著時全部人都睡著／把門窗全部塞緊，才暖得起來／在睡袋旁邊直接生火 | 燃燒會產生一氧化碳，在密閉空間會很危險，所以要留通風、有人輪流看著火、頭痛想睡要馬上到通風處。來源：州政府緊急管理手冊（車內取暖：保持排氣管暢通、留窗縫，睡著也很危險）。⚠ 「山屋室內」是我把這個原理套過去的，請老師確認說法，也要不要新增知識卡 K-CO。 | **是**（選「全部塞緊」或「在睡袋旁生火」＝C10 一氧化碳／火災） |
| S4 | 水快喝完了，窗外有很多雪。 | ✓ 先把雪放在鍋裡用火煮開（或放在水壺貼著身體裡面慢慢化），不要大量直接吃雪／抓一把地上的雪直接吃／水喝完就不用喝了 | 大量直接吃雪會讓體溫下降；雪也可能不乾淨，煮開最好。只靠雪水不夠，有其他飲料要一起喝。⚠ 「放水壺貼身化雪」來自戶外網站（可信度較低），建議老師決定要不要。 | 否（選「大量直接吃雪」也只是損失保暖值，不算 C） |
| S5 | 食物只夠兩天，但可能要等三天。 | ✓ 平均分成小份，慢慢吃，水要喝／一次吃完，才有力氣／不吃，省下來 | 先計畫、平均分配，不要一口氣吃光。⚠ 一般常識，來源沒寫細節；要不要放「不吃會更冷」要老師決定。 | 否 |
| S6 | 有人開始發抖、嘴唇發紫，保暖衣和毯子只夠一個人。 | ✓ 先給最冷、已經在發抖的人，包住身體，換掉濕衣服，墊在地上隔開寒氣／平均分配，大家都不夠暖／讓他自己撐 | 重用「失溫」卡：保暖、換濕衣服、隔絕地面冷氣。來源也提到可用墊子、地墊增加隔熱。 | 否 |
| S7 | 天氣好像小一點了，要不要自己下山求救？ | ✓ 留在山屋，用哨子與手電筒求救，等救援／自己一個人下山／全部人一起冒險下山 | 重用「迷路」「求救訊號」卡：除非有立即危險，不要離開避難處。 | **是**（選「一個人下山」＝C11，送回山腳村） |
| S8 | 夜裡輪流守夜，下面哪一個比較好？ | ✓ 輪流休息，互相看有沒有發抖、說話不清楚、想睡的人，叫醒大家／全部人一起睡到天亮／讓一個人從頭守到尾 | 來源（車內求生）：不要讓所有人同時睡著，輪流警戒。⚠ 這句我改寫成山屋版本。 | 否 |

### 結算（遊戲機制，不是題目）
每天結算保暖值、乾糧、開水；任何一項歸零就扣保暖值，保暖值歸零＝撐不下去（**請救援，扣 200，送回山腳村**）。撐到救援抵達（1～3 天）算成功，成功後才會繼續第 4、5 節。保暖衣、保暖毯、打火石、頭燈、哨子都有明確作用（用掉或決定結果），沒帶的人就會多撐得辛苦（但**不一定失敗**：好好分配仍有機會撐住）。

## 6. 新知識卡（草稿，要不要由老師決定）
（既有五張卡已涵蓋大部分，只有下面這些是新內容；不新增也可以，就用題目的解說帶過）
- **K-CO 室內取暖與通風**：燃燒會產生一氧化碳；要通風；不要在睡著時讓火一直燒；頭痛想睡要換到通風處。（來源：州緊急管理手冊、NPS 建議。）
- **K-WX 看預報決定上不上山**：風、降雪與氣溫；事先決定掉頭條件；山上比山腳更冷。（來源：NPS 風安全、山岳安全文章。）
- **K-RF 落石前兆**：下雨或融雪後、岩壁有新碎石與刮痕、小石滾落；不在岩壁下停留；落石時躲最大的岩石、停了再離開岩壁下方。（來源：NPS、各地步道管理處。）
- **K-WS 暴風雪中的水**：雪要煮開再喝；大量直接吃雪會變冷；水與食物要分配。
